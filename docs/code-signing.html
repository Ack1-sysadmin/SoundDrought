Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Signing starts as soon as the SignPath Foundation has approved the project. Releases up to and including v0.3.3 are not signed.

What gets signed

Only SoundDrought.exe, built from the source code in github.com/Ack1-sysadmin/SoundDrought. Every release is built by GitHub Actions from a tagged commit. No binary is ever built or signed on a personal machine. Each signing request is approved by hand.

Team roles

Changes from other contributors arrive as pull requests and are reviewed before they are merged. All team members use multi-factor authentication for GitHub and SignPath.

Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. The only exception is an update check against GitHub that sends no personal data and can be turned off. See the privacy policy for what the app connects to and why.
