SoundDrought

Privacy policy

SoundDrought has no servers, accounts, analytics or telemetry. The project itself never receives any data about you or how you use the app.

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. The only exception is the update check below, which sends no personal data and can be turned off.

What the app connects to

ConnectionWhyTheir privacy policy
soundcloud.com SoundDrought shows the regular SoundCloud website. You sign in and listen there, just like in your browser. SoundCloud
Sign-in providers (Google, Apple, Facebook) Only if you choose one of them on SoundCloud's sign-in page. Google · Apple · Meta
Discord app on your PC If Discord is running, SoundDrought tells it which track is playing (title, artist, artwork link, track link) so it can show "Listening to …" on your profile. You can turn this off in the tray menu ("Show Discord status"). Discord
GitHub (api.github.com) Update check: shortly after start and every 12 hours, SoundDrought asks GitHub which version is the newest release. The request contains no personal data, only the app version in the user agent. You can turn this off in the tray menu ("Check for updates"). The Microsoft Store version doesn't do this. GitHub
Microsoft Edge WebView2 The browser engine built into Windows that displays SoundCloud. It is part of Windows and follows Microsoft's settings for Edge. Microsoft

Links you open that lead away from SoundCloud open in your normal browser.

What is stored on your PC

  • %LOCALAPPDATA%\SoundDrought: window position, zoom, the last page and your settings, plus the WebView2 profile (SoundCloud cookies and sign-in) and a small diagnostic log (app.log).
  • If you turn on "Start with Windows", an entry named SoundDrought under HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run. It is removed when you turn the option off.

Uninstall

  1. Turn off "Start with Windows" in the tray menu (if you turned it on), then choose "Exit".
  2. Delete SoundDrought.exe. If you installed it with winget: winget uninstall Ack1.SoundDrought.
  3. Delete the folder %LOCALAPPDATA%\SoundDrought to remove your settings and sign-in.
